A list of commonly used Windows shortcuts and their equivalent on iPadOS with an external keyboard.

---

## 🧭 Navigation & System

| **Windows Shortcut** | **iPadOS Equivalent**         | **Function**                    |
|----------------------|-------------------------------|---------------------------------|
| Alt + Tab            | Command (⌘) + Tab             | Switch between open apps        |
| Windows + D          | F4 or swipe up with 4 fingers | Go to Home screen               |
| Alt + F4             | Command (⌘) + Q (if supported) | Quit app                        |
| Ctrl + Shift + Esc   | —                             | Not applicable (no Task Manager) |

---

## 🌐 Browser Shortcuts (Safari, Chrome)

| **Windows Shortcut** | **iPadOS Equivalent**        | **Function**               |
|----------------------|------------------------------|----------------------------|
| Alt + D / Ctrl + L   | Command (⌘) + L              | Focus address bar          |
| Ctrl + T             | Command (⌘) + T              | New tab                    |
| Ctrl + W             | Command (⌘) + W              | Close tab                  |
| Ctrl + Shift + T     | Shift + Command (⌘) + T      | Reopen closed tab          |
| Ctrl + Tab           | Control (^) + Tab            | Next tab                   |
| Ctrl + Shift + Tab   | Control (^) + Shift + Tab    | Previous tab               |
| Ctrl + R / F5        | Command (⌘) + R              | Refresh page               |
| Ctrl + D             | Command (⌘) + D              | Bookmark current page      |
| Ctrl + F             | Command (⌘) + F              | Find on page               |
| Ctrl + P             | Command (⌘) + P              | Print                      |
